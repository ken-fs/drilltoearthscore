Drill to Earth's Core has **four confirmed codes** as of **November 26, 2026**: **FORGE**, **FEAST**, **COMBAT** and **DRILL** (**500 Cores** each). **DTEC** and **GAMENAME** are disputed, so try them too. GAMENAME was the game's first redeem code — through September there was no code system at all, no Codes button in the lobby, and every "code" video for this game was actually showing codes for a different, similarly named Roblox title.

That last part still holds for most of the internet, so this page does two jobs: it lists the codes that work, and it tells you why every other list you find will not redeem in this game.

## What changed lately?

The November 14 Combat Rework brought a new code and retired an old one:

- **FORGE** — new. Listed on TryHardGuides, and Earnaldo redeemed it on video on November 26. Grants **500 Cores**.
- **FEAST** — Earnaldo redeemed it on video on November 21. Grants **500 Cores**.
- **COMBAT** — came with the Combat Rework. Listed on Pocket Tactics and Earnaldo, and Earnaldo redeemed it on video on November 19. Grants **500 Cores**.
- **DRILL** — still working. Listed on Pocket Tactics, Earnaldo and TryHardGuides. Grants **500 Cores**.
- **DTEC** — disputed. Pocket Tactics says expired, but Earnaldo redeemed it on video on November 19. Grants **500 Cores** if it works.
- **GAMENAME** — disputed. Pocket Tactics says expired, but Earnaldo has a video from October 4. Grants **500 Cores** if it works.
- **Expired:** **SOULPRISON** (retired by the Combat Rework), **HALLOWEEN** and **TRICKORTREAT** (ended with the Halloween event). Beebom, UrGameTips and TryHardGuides still list some of these, but their pages haven't been updated since early November.

## How do I redeem Drill to Earth's Core codes?

Redemption happens from the bottom of the screen, not the lobby menu:

1. Launch Drill to Earth's Core on Roblox and wait for your character to load.
2. Find the **Codes button** at the bottom of the screen — it is drawn as a present icon.
3. Enter the code in the **Enter Code Here** field, exactly as written (codes are case-sensitive — copy-paste, do not retype).
4. Press **Redeem**. The Cores land on your account immediately.
5. If nothing appears, **rejoin a fresh server** and try once more before assuming the code is dead.

## Why do other code lists fail in this game?

Because two games share almost the same name. **Dig to Earth's CORE!** by Slime Mine Studios is a different experience on a different place ID, and it is the one with a long-established code system. Lists that promise codes like `UPDATEHYPE`, `INDIGO`, `DIGGEM5000`, `moneymoneymoney` or `DOMINUSSS` are describing that game.

The tell: if a code list covers punching, pickaxes, pets and eggs, it is Dig to Earth's CORE!. This game — by the group literally called **Game Name.** — is the vehicle descent game with classes, Cores and the drill. When in doubt, check the Play link at the top of any guide before typing a code into the game.

## What is 500 Cores worth?

Cores are the currency that buys classes in the Academy, and 500 lands between the two cheap tiers:

| Class tier | Price | Examples |

| Tier 1 | 100 Cores | Miner |
| Tier 2 | 3,000 Cores | Witch |
