## What this log is

Drill to Earth's Core ships content fast — a new class has landed roughly every one to two weeks since launch — and the in-game update notes are not published anywhere official. So this log is built from the one source that never lags: **the game's own badge list**.

Every class, NPC, layer and system unlock has a badge, and the developers create the badge when the content is added. That makes the badge's creation date the release date — the same method behind every class date on this site, and the reason this log has exact dates where the Fandom wiki's update page still says "we are missing much info". Treat a date as the ship day, give or take a day for timezones.

## September 2026 (current season)

The busiest month so far — three class drops plus the update that finally unlocked the Mercenary.

| Date | What shipped | Notes |
| --- | --- | --- |
| 26 Sep | **Mercenary class + Lieutenant NPC go live** | Game updated 05:48 UTC; both badges began awarding within the hour. [Mercenary page](/classes/mercenary/) |
| 25 Sep | Lieutenant NPC badge created | "Talk to the Lieutenant" — staged, no unlocks yet |
| 23 Sep | Mercenary class badge created | The 27th class — staged in the game's data for two and a half days |
| 18 Sep | **Samurai class** | Tier 5, 30,000 Cores. Creator coverage of the same update documents Unranked mode and Death Crates. [Samurai page](/classes/samurai/) |
| 3 Sep | **Season 1: Prospector class + Simon the Shopkeeper** | Two badges created minutes apart — the class + NPC pairing that marks a new season. [Prospector page](/classes/prospector/) |

The September story in one line: content now gets **staged before it ships**. The Mercenary badge sat at zero unlocks for two and a half days, and the Lieutenant badge appeared the day before the update — both went live together on the 26th. The class + NPC pairing is familiar (Prospector and Shopkeeper were created 61 seconds apart on 3 September), but the gap between "in the game's data" and "reachable in game" is new.

## March 2026 (launch month)

The game page itself dates to 25 February 2026, but the first player-facing badges land in March — the **"Welcome" (join the game) badge on 13 March** is the best launch marker. Launch month built the whole skeleton of the game in three weeks:

- **Eight launch classes** — Miner, Scout, Tank, Gunslinger, Mechanic, Healer, Driller and Bruiser, with badges dated 13–14 March. Every one of them still costs 100–5,000 Cores.
- **The layer ladder** — Grass and Dirt (23 March), then Stone, Clay, Fossil, Crystal and Toxic (20 March), then Radioactive, The Abyss and The Void (19 March), ending at Reach the Core.
- **The economy and gear loops** — drill upgrades I–V (5 March), the armor tiers from Rusty to Void (9 March), ores from coal to ruby (9–10 March), wall damage (27 February–2 March).
- **The town NPCs** — Blacksmith, Mage and Banker (11 March), Merchant (26 February), then Postmaster (27 April) and the rest of the roster through the year.

## What's next

Nothing is announced, and the game's developers do not publish patch notes. Two things are worth watching, both from the badge API:

1. **A new badge appearing** = content staged. That is how the Mercenary and Lieutenant both showed up before they were reachable.
2. **That badge's first unlocks** = the content went live. This log and the [all classes page](/classes/all-classes/) both update from the same daily check.

If you are planning a build around the next class, the [class cadence](/classes/all-classes/) is the thing to read first — a class you save for can be superseded in a fortnight.
