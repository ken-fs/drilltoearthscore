## What we know about Mercenary

Mercenary is the newest class in Drill to Earth's Core — number 27 on the roster. The game's own unlock badge, **Unlock the Mercenary class**, was created on **23 September 2026**, and that is how every release date on this site is dated: the developers create a badge when a class is added to the game, so the badge list does not lag behind the way a hand-updated wiki does.

What the badge does not tell us is anything about the class itself. There is no price, no Academy tier, no starter gear and no ability list published anywhere we have found yet — not on the big aggregator sites, not in the creator videos that cover this game weekly, and not in the game itself. Every class in the game has four levels, with Level 4 a team bonus, so expect the same shape here once the kit is documented — but the specifics are still unknown.

Every blank in that table stays blank on purpose. A made-up price sends you grinding toward a number that does not exist, and a made-up kit is worse — it changes what you save for. Both get filled in from the same badge data and creator tests that produced the rest of this site.

## Is the Mercenary class out yet?

As of 26 September 2026, no. The Mercenary badge shows **zero unlocks** — not one player has the class. For scale, Samurai, added on 18 September, already sits at over a thousand unlocks.

The game also staged a second badge on 25 September: an NPC called the **Lieutenant** ("Talk to the Lieutenant"), also at zero unlocks. That pairing is the tell. On 3 September the developers created two badges minutes apart — Prospector (Unlock the Prospector class) and Shopkeeper (Talk to the Shopkeeper) — and both shipped in the same update. A class badge and an NPC badge appearing together, both unclaimed, is what an update in staging looks like.

## What to save while you wait

Both classes added in September — Prospector and Samurai — sit in the Tier 5 band at 30,000 Cores. If Mercenary follows that pattern, 30,000 is the number to save toward. The [get Cores guide](/guides/get-cores/) covers the fastest ways to bank them, and the [all classes page](/classes/all-classes/) has the full price ladder from Miner at 100 Cores upward.

This site's class data comes from the game's own badge API, re-checked every day. The moment the Mercenary class becomes unlockable, this page gets the price, the starter gear and a level-by-level table of the four passives — the same format as the [Samurai](/classes/samurai/) and [Prospector](/classes/prospector/) guides.
