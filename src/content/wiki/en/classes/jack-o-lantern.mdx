## Is Jack-o'-Lantern out?

No, not yet. The class's unlock badge, **Unlock the Jack-o'-Lantern class**, was created on **16 October 2026** (02:04 UTC). On 17 October it still had **zero unlocks**, so nobody can get it in game yet.

The game's last update was on 12 October. That's before the badge existed, which means the class is staged (added to the game's data) but not switched on.

Only the first row is solid. We leave the rest blank on purpose, because a made-up price would have you saving for a number that doesn't exist.

## Why we know it's coming

The developers create a badge whenever they add a class. That's why the badge list shows new classes before any guide does.

A new badge with zero unlocks means the class is staged. Its first unlocks mean it's live. Mercenary followed this exact path: badge on 23 September, live on 26 September.

## When it might go live

There's no announced date. The name points to Halloween on 31 October, but that's our guess, not a fact.

Badges usually go live within days. Mercenary took two and a half days. Engineer (1 October) and Vampire (7 October) are both awarding unlocks now, so the developers are shipping a class roughly every week this month.
