## Is Jack-o'-Lantern out?

Not yet, but it's close. The class's unlock badge, **Unlock the Jack-o'-Lantern class**, was created on **16 October 2026** (02:04 UTC). At 05:36 UTC on 17 October it still had **zero unlocks**.

The game updated at **05:25 UTC on 17 October**, and its name now ends in 🎃👻. The official **Halloween Event** on the game's Roblox page starts at **14:00 UTC the same day**. The developers' own words: "We are adding a new currency and a limited-time class you can earn!"

The event doesn't name the class. Jack-o'-Lantern is the only class that's staged (in the game's data but not switched on), so it's almost certainly the one.

## Why we know it's coming

The developers create a badge whenever they add a class. That's why the badge list shows new classes before any guide does.

A new badge with zero unlocks means the class is staged. Its first unlocks mean it's live. Mercenary followed this exact path: badge on 23 September, live on 26 September.

## When it might go live

Most likely when the Halloween event starts: **17 October 2026, 14:00 UTC**. The event's end date isn't published.

"Limited-time" matters here. If the class can only be earned during the event, don't put it off. Play the event early and stock up on the new currency.
